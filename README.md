# Sistema de Calificaciones

## Descripción
Sistema de Calificaciones es un programa de consola desarrollado en C# con .NET que utiliza un arreglo (vector) para almacenar las calificaciones de cinco estudiantes. El programa muestra todas las notas recorriendo el vector con un ciclo for, permite consultar una calificación específica mediante su índice, calcula el promedio del grupo, identifica la nota más alta y la más baja, cuenta cuántos estudiantes aprobaron y cuántos reprobaron (nota mínima de 70), y permite modificar la calificación de un estudiante para luego mostrar el vector actualizado. Fue desarrollado como actividad del Capítulo IX (Arreglos y Vectores) de la asignatura Introducción a la Programación.

## Objetivo
Aplicar los conceptos de arreglos, índices y vectores en un programa sencillo, usando ciclos, condiciones y cálculos sobre un conjunto de datos.

## Lenguaje utilizado
C# (.NET 8, aplicación de consola)

## Funcionalidades desarrolladas
- Vector con 5 calificaciones: `{ 85, 67, 92, 74, 58 }`
- Mostrar todas las calificaciones con un ciclo `for`
- Acceso a elementos mediante índices
- Cálculo del promedio
- Nota más alta y nota más baja
- Conteo de aprobados y reprobados (nota mínima: 70) con `if`
- Modificación de una calificación
- Mostrar el vector actualizado

## Instrucciones para ejecutar
1. Instalar el SDK de .NET desde https://dotnet.microsoft.com/download
2. Clonar o descargar este repositorio.
3. Abrir una terminal en la carpeta del proyecto y ejecutar:

```bash
dotnet run
```

También se puede abrir el proyecto en Visual Studio y presionar F5.
